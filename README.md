# WindFlow AI

Agentic AI-система для почасового прогнозирования нормализованной выработки двух
ветровых турбин на горизонте 24-48 часов.

## Первый прототип

- FastAPI backend с проверкой состояния и описанием этапов агента.
- React/Vite dashboard для запуска и просмотра прогноза.
- Изолированное Python-окружение и lock-файл через `uv`.
- Архитектура для загрузки архивных прогнозов погоды, подготовки признаков,
  ML-прогнозирования и проверки результата.

## Структура

```text
backend/   FastAPI, агентный pipeline и ML-модель
frontend/  React/Vite dashboard
data/      локальные исходные и подготовленные данные (не коммитятся)
```

## Запуск backend

```powershell
cd backend
uv sync
uv run uvicorn app.main:app --reload
```

API: `http://localhost:8000`, Swagger: `http://localhost:8000/docs`.

## Запуск frontend

```powershell
cd frontend
npm install
npm run dev
```

Интерфейс: `http://localhost:5173`.

## План Agentic AI

1. Получить архивный прогноз погоды, доступный на дату расчета.
2. Проверить полноту, временную зону и единицы измерения.
3. Подготовить погодные и календарные признаки.
4. Выбрать модель турбины и горизонт 24/48 часов.
5. Рассчитать и проверить прогноз на физические ограничения.
6. При ошибке данных повторить запрос или применить безопасный fallback.
7. Сохранить прогноз, метрики качества и журнал действий агента.

Основная функциональность разрабатывается во время HackAlem AI 2026.
