# Соответствие заданию

WindFlow AI реализует полный цикл прогнозирования почасовой нормализованной
мощности двух ветротурбин на 24–48 часов.

## Обязательные требования

| Требование | Реализация | Как проверить |
| --- | --- | --- |
| Модель почасового прогноза | Отдельные модели для двух турбин и часов 1–24/25–48 | Вкладка «Проверка качества», backend/models/metrics.json |
| Получение погодных прогнозов | Open-Meteo Previous Runs, retry, cache и offline-архив | Этап weather, поле data_source |
| Горизонт 24–48 часов | Выбирается в dashboard и API | POST /api/jobs |
| Последовательный февраль 2026 | 28 выпусков, по 672 уникальных часа на турбину | Кнопка «Февраль», scripts.export_submission |
| Историческая реконструкция | Используются поля с упреждением previous day 1/2 | docs/FORECAST_PROTOCOL.md |
| Agentic AI | Семь наблюдаемых этапов, retry, выбор модели, контроль результата | Журнал агента и GET /api/jobs/{job_id} |
| Обновление расчёта | Повторный запуск заменяет логический прогноз без дублей | История и тесты идемпотентности |

## Результаты

- React-dashboard для запуска и анализа.
- Графики мощности, ветра, факта и прогноза.
- Почасовая таблица с оценочным диапазоном ошибки.
- История успешных и неудачных заданий.
- PDF-отчёт для управленческого использования.
- Excel-книга для анализа.
- CSV для статистической обработки.
- Полный февральский offline-архив Open-Meteo с SHA-256 и манифестом.
- CLI для ежедневного запуска и пакетного экспорта.

## Проверка репозитория

~~~powershell
.\run.ps1 -SkipInstall -Check
~~~

Ручной полный февральский расчёт:

~~~powershell
cd backend
uv run python -m scripts.export_submission --offline
~~~

Ожидаемый результат в artifacts/submission/:

- turbine_1_february.csv — 672 часа;
- turbine_2_february.csv — 672 часа;
- manifest.json;
- metrics.json.

## Воспроизводимость

Репозиторий содержит production- и validation-модели, январские проверочные
предсказания, реальные архивные прогнозы погоды и отчёты выбора моделей.
Исходные пользовательские CSV, локальная база, кэши и секреты в Git не входят.
Приложение запускается без API-ключей.

Точная методика временного разделения, интерпретация метрик и ограничение
Open-Meteo Previous Runs описаны в [FORECAST_PROTOCOL.md](FORECAST_PROTOCOL.md).
