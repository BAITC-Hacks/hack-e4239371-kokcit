# Что сдаём

WindFlow AI прогнозирует почасовую нормализованную мощность двух ветротурбин
на 24–48 часов по доступным на момент выпуска прогнозам погоды.

## Обязательный результат

- [x] Запуск по README, январское демо без погодного API; Docker runtime ещё не проверен.
- [x] Обе турбины, горизонты 24 и 48 часов, график и почасовая таблица.
- [ ] 28 ежедневных запусков для февраля 2026, полный CSV без пропусков и дубликатов.
- [x] Реальное выполнение и журнал шагов: погода → проверка → признаки → модель →
      контроль результата → сохранение. Ошибки, повторные попытки и источник данных видны.
- [x] Явное время выпуска; ограничение точной доступности погоды описано в протоколе.
- [x] Проверка модели на январе 2026 отдельно от обучения, сравнение с простым baseline.
- [x] Воспроизводимые метрики, график факт/прогноз и инструкция переобучения.
- [x] Автоматический ежедневный запуск через CLI/планировщик.
- [x] Проверка API, ошибочных входных данных, экспорта и production-сборки.

Осталось скачать реальную февральскую погоду через `scripts.prepare_demo` и
сформировать оба CSV через `scripts.export_submission --offline`. В текущей
среде сетевое скачивание недоступно; месяц проверен на синтетической тестовой
фикстуре, январская работа реальных моделей проверена на сохранённой погоде.
Для строгой доступности данных по конкретному времени выпуска требуется
архив отдельных метеорологических выпусков — см. `FORECAST_PROTOCOL.md`.

## Цель качества

Стремимся к R² > 0.80 и снижению MAE для обеих турбин и обоих горизонтов.
Это целевой показатель, а не обещанный результат. Публикуем фактические метрики;
не используем будущие измерения ветра или мощности в признаках прогноза.
Нормализованная мощность 0–1 не является мощностью в МВт без номинала турбины.
